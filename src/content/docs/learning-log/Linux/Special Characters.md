`* ? []` Match multiple file or directory names 
`$` Expands variables 
`|` Pipe
`> < >>` Redirection 
`&` Runs a process in the background 
`;` Separates multiple commands on a single line 
`~` Shortcut for the user's home directory 

```bash
echo "The server costs \$100 a month"
```
